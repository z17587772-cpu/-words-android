# Listening catalog publishing area

This folder is hosted from the `content-inbox` branch.

The manual publisher workflow expects:

- `unsigned_catalog.json`: reviewed catalog payload, schema version 1.
- `catalog.json`: generated signed envelope. Do not edit this file by hand.

Each package entry in `unsigned_catalog.json` must contain:

- `package_id` (unique within the catalog)
- `package_version`
- `minimum_app_version_code`
- `url` (raw.githubusercontent.com URL on this repository's `content-inbox` branch)
- `size_bytes`
- `sha256`

The catalog root must contain `schema_version: 1`, a monotonically increasing positive `catalog_version`, and a `packages` array.

Only fully reviewed, rights-cleared production courses may be listed. Candidate inbox records are not courses. Do not publish an empty placeholder catalog or a package that has not passed the full editorial and rights review.

Run the **Publish signed listening catalog** workflow manually after package files and the unsigned catalog are ready. The workflow checks local package bytes, signs the canonical payload, and commits only the signed catalog.
