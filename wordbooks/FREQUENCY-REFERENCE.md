# 词频来源与排序口径

应用把“课程/词表重要度”和“语料出现次数”分开存储、展示与计算。

## 1. 课标权重
`importance` 沿用 2025 版词表源文件中的级别标记。它代表词表级别/课程要求，不是历年高考出现次数。当前 2025 修订新课标核心词书有 3,097 条应用记录；结构化来源有 3,099 个词头，其中 China/china、Miss/miss 两组因应用数据库不区分大小写而合并。该计数口径不等于独立认证的官方唯一词数。

## 2. 第三方综合语料参考
- 项目：<https://github.com/ZhangYixuan-in-BUPT/english-word-frequencies>
- 固定提交：`676ae3cfecfc77e29c2e22317efa8e153aff9c45`
- 数据文件：`word_frequencies_data.zip`
- 上游 README 描述 17,239 个词汇记录，语料为高考真题与高中教材，提供 high / medium / low 分级。
- 许可证：MIT；构建时将上游 `LICENSE` 一并复制到 APK 的 `assets/licenses/english-word-frequencies-MIT.txt`。

**重要限制：** 上游没有完整公开纳入的试卷/教材清单、分词规则、词形还原规则与逐条统计明细。本项目因此把这组数据称为“第三方综合语料参考”，不标成官方或完整的高考单独词频。缺少匹配的词条使用 `corpus_frequency=-1`、空分级，不将缺失误写成 0 次。

数据由 `tools/enrich_wordbooks.py` 固定版本抓取、按小写词形匹配。原始课标权重不被覆盖。

## 3. 采样策略
- 背词：综合课标权重、语料分级、掌握度、距离上次复习时间和曝光次数。
- 随刷：只综合课标权重、语料分级和轻微收藏偏好；不读取/修改掌握度与复习时间。
- 两种模式均采用加权无放回排序，当前轮内不重复；最近看过的词会推迟到队列尾部，而不是永久过滤。
