## Database v14 content-hash protection
- books.content_sha256 is added through a non-destructive schema migration.
- parsePack computes SHA-256 over the exact UTF-8 source JSON.
- seedBuiltInPack updates on first install, higher pack version, or same version with different content hash.
- A lower incoming pack version never replaces a higher installed version.
- installPack reuses matching word IDs, deactivates removed headwords instead of deleting them, and preserves reviews/history/favorites for retained words.
- Instrumentation tests cover v5-to-v14 migration preservation, same-version content change, downgrade rejection logic and word ID / review / history preservation.
- Application-level regression added: run seedBuiltInPack against all 11 packaged assets and verify DB entry counts/hashes and idempotence. The latest validation-only CI run is pending; it must not produce an APK.
