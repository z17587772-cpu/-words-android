words Android v1.4.0 — implementation status

Implemented in source:
- 随刷: configurable no-mask / hide-English / hide-Chinese mode; reveal action, no learning progress writes.
- 背词: daily goal queue, four answer options, English→Chinese / Chinese→English / alternating direction.
- Instant correct/incorrect feedback; each answer saves a review event once; skip does not mark right/wrong.
- Answer detail card displays local pronunciation, POS, Chinese meaning, example and TTS.
- Online dictionary client uses FreeDictionaryAPI.com / Wiktionary response structure.
- Online lookup supports definitions, forms, examples, synonyms, antonyms and available Chinese translations.
- Dictionary responses are cached in SQLite table word_detail_cache for offline revisits.
- Online source and CC BY-SA 4.0 license attribution are shown.
- Existing TTS locale configuration, cross-wordbook favorites, and vector launcher artwork retained.

Validation still required:
- Run GitHub Actions Android build.
- Inspect resulting APK and confirm all resource/permission entries and app version 1.4.0.
- Test on a real device with network available and without network. API availability and field coverage depend on the remote service; empty fields are intentionally not invented.

Data limitations:
- Core curriculum extraction: 2,974 records; approximately 126 still require reconciliation against the stated ~3,100 target.
- Third-party frequency source is a combined exam-paper/textbook corpus, not an official complete Gaokao-only count.
- Online dictionary entries are contributed from Wiktionary and may vary by word. No guarantee of root etymology, collocation, source exam, or picture for every entry.

Build:
- JDK 17, Android SDK Platform 35 / Build Tools 35.0.0, Gradle 8.9.
- Run gradle --no-daemon clean assembleDebug from android/.
