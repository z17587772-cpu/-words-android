words Android v1.5.0 — implementation status

Implemented in source:
- Quick Browse removed the next-word button; left/right horizontal card swipe moves between words with directional animation.
- Browse setting keeps none / hide English / hide Chinese masking.
- Daily Quiz retains the source question after choosing; correct option and chosen wrong option receive separate highlights and correctness feedback.
- Tapping any option after answering opens the detail explanation; answers are persisted exactly once.
- Larger question card and entry animations.
- Explanation hierarchy: answer result, headword, core meaning, example sentence, optional translation, online definitions/forms/examples/synonyms/antonyms and source.
- Local example translations are preferred; MyMemory machine-translation fallback is labelled and cached in SQLite.
- Sound and vibration feedback can be turned on/off independently in settings.
- FreeDictionaryAPI/Wiktionary response parser includes entry-level and sense-level synonyms/antonyms.
- Database v4 adds example translation cache without deleting prior reviews, favorites or dictionary details.

Validation:
- Pending final GitHub Actions build and APK inspection.

Limitations:
- Example machine translation depends on network and MyMemory anonymous daily quota (official docs specify 5,000 characters/day anonymous).
- Third-party dictionary entries vary; roots, collocations and exam-source tags are not invented when the API does not supply them.
- Core 2025 wordbook still contains 2,974 entries, with approximately 126 remaining to reconcile.

Build:
- JDK 17, Android SDK Platform 35 / Build Tools 35.0.0, Gradle 8.9.
