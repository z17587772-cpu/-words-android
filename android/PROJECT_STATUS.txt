words Android v1.2.1 — implementation status

Completed:
- v1.2.1 UI refinement: Quick Browse next button is fixed above navigation; study reveal card minimum height reduced from 500dp to 360dp; launcher mark simplified with a white background and indigo/periwinkle folded-page symbol.
- Native Kotlin Android app with offline SQLite persistence and Android TTS.
- Repository normalized to a conventional android/ source tree; obsolete source_chunks/ and source_archive/ transport folders removed.
- 随刷 is the first/default navigation entry and is an unlimited vocabulary browsing mode.
- 随刷 has an independent queue, cursor, recent-view cooldown and browse counter. It shows no familiarity ratings and does not alter mastery, review records, or daily progress.
- 背词 remains a separate daily study workflow with reveal interaction, mastery feedback, review history and statistics.
- Weighted permutation sampler runs without replacement. Each browse cycle covers the full active book, and recent words are deferred.
- Vocabulary cards were enlarged; navigation hierarchy, page/card transitions and adaptive launcher icon were refreshed.
- SQLite v1-to-v2 migration adds corpus frequency metadata while preserving existing review rows and favorites.
- Wordbooks retain curriculum importance tiers and add separately attributed third-party combined-corpus frequency references.
- Android build completed successfully in GitHub Actions; APK and source artifacts were uploaded and Release v1.2.1 was published.

Data limitations:
- Core curriculum extraction currently contains 2,974 entries; approximately 126 entries remain to reconcile against the stated ~3,100-word curriculum target.
- External frequency reference combines exam papers and textbooks. It is not an official, complete Gaokao-only frequency count.
- Pronunciation uses device TTS. Phonetics, example sentences and audio coverage are not uniform for every entry.
- APK is debug-signed for testing, not production store distribution.

Build:
- JDK 17, Android SDK Platform 35 / Build Tools 35.0.0, Gradle 8.9.
- Run `gradle --no-daemon clean assembleDebug` from this directory.
